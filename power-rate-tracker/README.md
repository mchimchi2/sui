# 電力単価トラッカー(大手電力10社)

急速充電器の電気代試算のために、大手電力10社の高圧プランの電力単価を一覧管理し、
使用量を入力すると月額料金を試算できるツールです。
サーバー不要・`index.html` をブラウザで開くだけで動作します。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 一覧表示・料金試算・単価編集のUI |
| `rates.js` | 単価マスタデータ(チーム共有はこのファイルをGit管理) |

## 一覧に含まれる料金構成要素

- **基本料金**(円/kW・月)— 契約電力に応じて課金。力率割引 `×(185−力率)/100` に対応
- **電力量料金**(円/kWh)— 夏季(7〜9月)/その他季の2区分
- **燃料費調整単価**(円/kWh)— **毎月改定**。初期状態は「⚠ 要入力」
- **再エネ賦課金**(円/kWh)— 全社共通、**毎年5月改定**
- **更新日** — 単価を編集して保存すると、変更した行だけ自動で当日日付に更新
- **出典URL** — 各社公式料金ページへのリンク

契約電力(kW)・使用量(kWh)は初期状態で空欄です。入力すると以下の式で月額(税込)を試算します。

```
月額 = 基本料金 × 契約電力 × (185 − 力率)/100
     +(電力量料金[季節別] + 燃料費調整 + 再エネ賦課金)× 使用量
```

## 毎月の更新運用

1. `index.html` を開き「✏️ 単価を編集」をクリック
2. 各社の当月の燃料費調整単価(各社が毎月公表)を入力
3. 「💾 保存」→ 変更した行の**更新日が自動で当日**になる
4. チームで共有する場合は「⬇ JSONエクスポート」した内容を `rates.js` の
   `RATE_DATA` に反映してコミット(ブラウザ編集は localStorage 保存のため個人環境のみ)

年1回(5月)は再エネ賦課金、随時、各社の料金改定(基本料金・電力量料金)を反映してください。

## ⚠ 初期データについて

`rates.js` の単価は**構築時点の参考値**です。実運用前に必ず各社公式ページ
(一覧の出典リンク)で最新単価を確認・更新してください。
特に燃料費調整単価は毎月変わるため、未入力(⚠表示)のままでは試算が過小になります。
