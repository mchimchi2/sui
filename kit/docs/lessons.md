# 踏んだ罠と対処(制作前に必読)

## 動画・HyperFrames
- **iPhone動画はHDR(HLG/bt2020)**。そのまま使うとHyperFramesが「HDR layered」モードになり書き出しが数倍遅い → prepare_assets.py の zscale+tonemap で SDR(bt709)に変換してから使う
- `letterSpacing` をGSAPで動かすと lint エラー(ピクセルスナップで揺れる) → `scaleX` で代用
- `fromTo` は作成時に from の値を即適用する。フラッシュ用の白幕に fromTo(opacity:1→0) を使うと冒頭から画面が白くなった → `tl.set` + `tl.to` に分ける
- 日本語フォントは `@font-face { src: local("Noto Serif CJK JP") }` で宣言しないと lint が通らない/意図しない書体になる。Mac で未インストールなら Noto Serif JP を入れるか local() 名を変更
- クラウド環境では1コマンド300秒制限のため 30秒を3パート×10秒に分割してレンダー→ffmpeg concat した。ローカルなら1本にまとめても良い
- 書き出し後は snapshot で複数時刻を画像確認(白飛び・文字の崩れ・人物の写り込み)

## 素材・権利
- 大人の顔: 顔の楕円領域だけガウスぼかし(blur.py)。周囲の他の乗客の顔も忘れずに
- 人物の「消去」はしていない。人が写らない位置でトリミング/拡大で対応
- 献立の紙に「〇〇様」(宿泊者名)が印字されていた → inpaint で消去。座標は写真ごとに要確認
- 駅の広告にアニメキャラ(著作物)が写っていた → トリミングで外した
- 公式サイトの画像は使わない(docs/strategy.md の絶対ルール)

## 音
- BGMはすべて numpy で自作したオリジナル(著作権フリー)。ラウドネスは -14 LUFS に正規化
- 見せ場(ハードカット)にコード解決・ベル・インパクト音を合わせると効く
- 声(ナレーション)は未実装。入れるなら CapCut の読み上げ or 本人録音。声の区間はBGMを20〜30%に
